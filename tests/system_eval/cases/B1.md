## 用户输入

用 Java + Flink 1.18.1 开发一个 Kafka 流式 WordCount：

- Kafka bootstrap：`node1:9092`；
- topic：`$words_topic`；
- group id：`eval-wordcount-$run_id`；
- 消息是普通字符串，按空格切词；
- 使用 **5 秒滚动处理时间窗口**，窗口结束时打印每个单词的出现次数，格式 `word=..., count=...`；
- 使用 DataStream 的 `KafkaSource<String>`（`org.apache.flink.connector.kafka.source.KafkaSource`），不要用 Flink SQL；
- 并行度 1；JM 768m、TM 1024m、1 个 slot（这些约束写进提交信息）；
- 代码写到项目里，主类放在 `src/main/java/com/fm`；
- **先不要提交到集群**；完成后说明 Maven 依赖、编译情况和未验证风险。
