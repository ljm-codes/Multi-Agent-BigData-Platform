## 用户输入

用 Python + Spark 分析 Hive 表 `fireflymall.userbehaviordata`（HiveServer2 在 `node1:10000`，库 `fireflymall`）。

统计 `dt` 在 `2026-03-24` 到 `2026-03-28`（含两端）这 5 个分区每天的行为记录数，按 `dt` 升序打印，格式为：

```text
dt=2026-03-24, cnt=...
```

要求：

- 主文件用 Spark SQL 读取该 Hive 表（`enableHiveSupport`），不要用本地造假的 DataFrame；
- 代码写到项目里，主文件放在 `src/main/python`；
- 开发完成后提交到 YARN 运行；
- 提交参数控制在 1 个 executor、executor 内存 1g、driver 内存 1g 以内。
