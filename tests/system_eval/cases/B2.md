## 用户输入

用 Java + Flink 1.18.1 从 Kafka 实时统计 PV/UV：

- Kafka bootstrap：`node1:9092`；
- topic：`$events_topic`；
- group id：`eval-pvuv-$run_id`；
- 消息是 JSON：`{"user_id": "...", "event": "...", "ts": 1700000000000}`，`ts` 是 epoch 毫秒；
- 事件时间语义，watermark 延迟 5 秒；
- 10 秒滚动窗口；
- 每个窗口按 `event` 统计 PV 和去重 UV（按 `user_id`），打印格式：

```text
window=[start,end) event=search pv=3 uv=3
```

- 使用 DataStream 的 `KafkaSource<String>` + Jackson 解析 JSON；
- 并行度 1；JM 768m、TM 1024m、1 个 slot（写进提交信息）；
- 主类放在 `src/main/java/com/fm`；
- 开发完成后提交到 YARN 运行。
