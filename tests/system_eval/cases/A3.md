## 用户输入

用 Python + Spark 对 Hive 表 `fireflymall.userbehaviordata` 做用户行为漏斗分析，范围 `dt` 在 `2026-03-24` 到 `2026-03-28`（含两端）。

口径：

- 按 `dt` 分组；
- 分别统计 `type` 为 `search`、`cart`、`order`、`payStatus` 的**去重 userid 数**（UV）；
- 计算三级转化率：`cart_uv/search_uv`、`order_uv/cart_uv`、`payStatus_uv/order_uv`；
- 分母为 0 时输出 0，不能除零报错。

输出要求：

- 按 `dt` 升序打印：`dt=..., search_uv=..., cart_uv=..., order_uv=..., payStatus_uv=..., cart_rate=..., order_rate=..., pay_rate=...`；
- 转化率保留 4 位小数；
- 使用 Spark SQL 读取 Hive 表（`enableHiveSupport`）；
- 代码写到项目里，主文件放在 `src/main/python`；
- 开发完成后提交到 YARN 运行；提交参数控制在 1 个 executor、executor 内存 1g、driver 内存 1g 以内。
